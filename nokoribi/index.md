# のこりび / Nokoribi

カップル向けカウントダウン＆バケットリストアプリです。残りの人生の日数を可視化し、パートナーと一緒にやりたいことリストを管理できます。

A couple-focused countdown and bucket list app. Visualize the remaining days of your life and manage a shared bucket list with your partner.

---

## 主な機能 / Features

### 無料機能 / Free Features
- **残り日数カウントダウン** - 厚労省の簡易生命表に基づく残り日数を表示
- **バケットリスト管理** - やりたいことリストの作成・管理
- **カップルモード** - パートナーとバケットリストを共有
- **基本ウィジェット** - ホーム画面で残り日数を確認
- **寿命進捗バー** - 人生の進捗を可視化

### Pro機能 / Pro Features
- **広告非表示** - すべての広告を削除
- **フォトメモリー** - 達成記録に最大3枚の写真を添付
- **テーマカラーカスタマイズ** - 7種類のプリセットテーマ
- **詳細ペース分析** - 人生のペースを詳しく分析
- **ウィジェットカスタマイズ** - ウィジェットの表示をカスタマイズ
- **カスタム目標日** - 自由に目標日を設定
